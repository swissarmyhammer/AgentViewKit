# Language icons

The icons of the `languages` module of the status line (D194 (i)). The name
of each file is the name of a builtin language of `StatusLineLanguages` and
the name of its `icon:` symbol.

Source: Simple Icons 13.21.0 (`https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/`).
License: CC0 1.0 Universal (`LICENSE.md`). The files are as Simple Icons
gives them.
