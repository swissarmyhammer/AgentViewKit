## What
Create the record types in `Sources/AgentViewKit/Model/`, per plan.md §3.2. `JSONValue` comes from its own task.

- `ThreadRecord.swift`: `public protocol ThreadRecord: AnyObject, Identifiable, Observable` with `id: String`, `revision: Int`, `meta: JSONValue?`.
- `ThreadItem.swift`: `public enum ThreadItem` with cases `system(SystemPrompt)`, `userMessage(Message)`, `assistantMessage(Message)`, `reasoning(Reasoning)`, `toolCall(ToolCallRecord)`, `structured(StructuredRecord)`, `compaction(CompactionMarker)`, `error(ThreadError)`, `unknown(UnknownRecord)`. Add `var record: any ThreadRecord` and `var id: String`.
- One `@Observable final class` per record, each with `id`, `revision`, `meta`, and a `bump()` that increments `revision`.
- `ContentBlock.swift`: `text`, `image`, `audio`, `resourceLink(name, uri, icons, mimeType)`, `resource(text or blob)`, `attachment(URL)`, `structured(schemaName, payload)`, `unknown(kind, raw)`. Each block carries optional `Annotations` with `audience: [Audience]` and `priority: Double?`.
- `ToolCallRecord`: `title`, `kind` (`read, edit, delete, move, search, execute, think, fetch, switchMode, other, unknown(String)`), `status` (`pending, inProgress, completed, failed, cancelled, lost, unknown(String)`), `content: [ToolContent]` (`block`, `diff(patch)`, `terminal(id)`), `locations`, `rawInput`, `rawOutput`, `startedAt`, `endedAt`.
- `ThreadError`: `contextSizeExceeded(contextSize, tokenCount)`, `rateLimited(resetAt)`, `guardrailViolation(explanation)`, `refusal(explanation)`, `timeout`, `acp(code, message)`, `unknown(message)`.
- The payload for `structured` is `GeneratedContent`-free in this target: store a `JSONValue`. The FoundationModels target converts.
- Enums with an `unknown(String)` case: `ToolKind`, `ToolCallStatus`, `Audience`.
