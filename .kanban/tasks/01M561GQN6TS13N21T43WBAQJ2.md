title: Stop AppKit from opening a bare launch argument as a document in the demo UI tests

Request from swissarmyhammer-96 (decision (c)). CI run 39072794341 attempt 2 on mini-01 (Xcode 27.1): GalleryTabEndToEndTests failed because the app started with `--tab gallery` and opened no window. AppKit can treat a value that does not start with "-" ("gallery") as a document to open. Then it opens no window.

## Work
- In one shared place of `Examples/AgentViewKitDemo/Tests`, add `"-NSTreatUnknownArgumentsAsOpen", "NO"` to the launch arguments of each UI test, not only the Gallery test. Add a comment that says why.
- Do not change the demo argument format.

## Proof
The CI run of this push. If the Gallery test passes on mini-01 or m5u1 with Xcode 27.1, the cause is confirmed. If it still fails, stop and tell the coordinator (then do (a)).
