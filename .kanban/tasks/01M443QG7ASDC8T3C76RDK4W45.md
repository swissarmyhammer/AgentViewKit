## What
Source: update.md §4.3 (session list, close, delete, capability flags), §4.7 ("Session picker", "Capabilities"), §8 item 2. Owner rule (2026-10-06): the picker binds directly to the observable model of FoundationModelsACPClient. It shows what `ConnectionModel` holds and calls its methods. The kit keeps no session list of its own: at present `SessionListModel` (`Sources/AgentViewKit/Sessions/SessionListModel.swift`) keeps a copy of the pages (`sessions`, `nextCursor`, `hasLoadedFirstPage`) from its own `SessionListProvider`.

- [ ] `SessionListView` (`Sources/AgentViewKit/Sessions/SessionListView.swift`) takes the `ConnectionModel` and reads `ConnectionModel.sessions` (ACP `SessionInfo`) and `hasMoreSessions` directly. Delete the page copy of `SessionListModel` and the `SessionListProvider` protocol. The search text stays view state (`@State`); the filter is a pure function of `ConnectionModel.sessions`. Remove the kit `SessionSummary`.
- [ ] Show "Load more" when `hasMoreSessions` is true; it calls `loadMoreSessions()`. Refresh calls `refreshSessions(cwd:)`. A failure shows the error of the call; the list keeps the values of the model.
- [ ] A delete action calls `deleteSession(_:)`. Hide it when `canDeleteSessions` is false. Hide the list when `canListSessions` is false. Hide resume when `canResumeSessions` is false. Each flag is read from the model at the time of the body.
- [ ] When a thread view closes, call `ConnectionModel.close(_:)` (when `canCloseSessions` is true). At present nobody sends `session/close`.
- [ ] A selected session resumes with `ConnectionModel.resumeSession(_:)` and `replayFrom: .start`.

## Acceptance Criteria
- [ ] Two pages of sessions show after one "Load more", from `ConnectionModel.sessions`.
- [ ] A `session_info_update` of an open session changes its row title with no other step.
- [ ] With `canDeleteSessions` false, no delete control shows. A delete sends `session/delete` and the row goes away when the model removes it.
- [ ] Close of a thread sends `session/close`.
- [ ] No source in `Sources/AgentViewKit/Sessions/` keeps a copy of the session list or of a page cursor.
