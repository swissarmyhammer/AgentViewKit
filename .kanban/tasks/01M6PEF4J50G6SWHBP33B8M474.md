User decision (2026-11-05): add Stencil to AgentViewKit as a direct dependency. The text audit (^688qj5d) left nine places that build longer text in loops:
- **T1:** ThreadExporter, the Markdown export.
- **T2:** AgentCommandTarget.plainText, the copy text.
- **T3:** the plan "Steps" inspector field.
- **T4:** ElicitationView field error text.
- **T5:** the four "A › B › C" paths: the who-asks visible line, SessionPathText.label, SessionJumpList.pathText and the SessionTreeBanners explanation.

## What
- Add Stencil (the same package and version the skills use, found through FoundationModelsExtras' manifest) as a direct dependency of AgentViewKit.
- Templates live as bundle resources, loaded through one small AVK renderer. Render each from a plain model value.
- T1, T2 and T3 become templates.
- For T4 and T5, prefer one catalog format string per item plus the locale's list or path pattern if that's cleaner than a template. Decide per site and record why. Separators and order belong in templates or the catalog, never in code.
- Localizable words inside templates come from the catalog, passed in the model, unless the template itself is localized. Record the approach.

## Tests
- [ ] Each converted site keeps its output for a fixed locale, as characterization tests, plus a test that a template edit changes the output with no code change.
- [ ] Full AVK suite green, zero AVK warnings.
