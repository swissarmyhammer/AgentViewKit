## What
Create `Sources/AgentViewKit/Input/SuggestionsView.swift`, `SpeechInputButton.swift`, and `ToolToggles.swift`, per plan.md §9 D.

- `SuggestionsView(suggestions: [String])`: a horizontal row of glass chips; a tap sets the composer text through the `PromptEditorContext` binding. Hidden when empty. Shown in the empty state and after a turn when the host provides follow-ups.
- `SpeechInputButton`: a mic button in the composer accessory. Uses `SFSpeechRecognizer` behind a `SpeechTranscriber` protocol with an injected fake for tests. While recording, the button shows a level indicator and the live transcript goes into the composer text. Requests permission through the protocol, so tests do not touch the system.
- `ToolToggles(tools: [ToolToggle])`: a menu of switches in the composer accessory that call a host closure `onToggle(id, Bool)`. Reads the tool list from the ambient `ConnectionStore` when present.
- `DefaultPromptAccessory` gains slots for the three, each hidden when its data is absent.

## Acceptance Criteria
- [ ] A tap on a suggestion sets the composer text to it.
- [ ] With the fake transcriber, pressing the mic then feeding "hello" puts "hello" in the composer text.
- [ ] A tool toggle calls `onToggle` with the id and the new value.
