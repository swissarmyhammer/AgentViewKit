## What
Owner rule (2026-10-06): each kit view binds directly to the observable model of FoundationModelsACPClient, and calls the model methods. At present the agent command scope reads only an `AgentThread` and calls `AgentThreadActions`, so a thread view over a `SessionModel` has no agent commands. `AgentCommandTarget.isIdle(_:)` reads the kit `ThreadState`, and `jumpTarget(forward:)`, `toggleExpandAll(_:)` and `plainText(of:)` read `thread.items`.

- [x] `Sources/AgentViewKit/Commands/AgentCommandTarget.swift`: the target holds a `SessionModel`. `cancel` is available while `agentState` is `.running` or `.requiresAction`, and calls `SessionModel.cancel(meta:)`. `send` with a payload calls `SessionModel.prompt(_:meta:)`. `approvePending` and `rejectPending` read `SessionModel.pendingPermissions` and call `selectPermission(_:option:)`.
- [x] In the same file: `copyThread` and `plainText` read the `UserMessageEntry` and `AgentMessageEntry` objects of `SessionModel.transcript`. `jumpToNext` and `jumpToPrevious` go to the next or the previous `UserMessageEntry` in the transcript order. `toggleExpandAll` reads the row keys of the transcript. The target keeps no copy of these values.
- [x] `Sources/AgentViewKit/Commands/AgentCommandScope.swift`: add `agentCommandScope(session:)`. The focus segment uses the identity of the `SessionModel` (`sessionId`).
- [x] `Sources/AgentViewKit/Thread/AgentThreadView.swift`: the session path applies `agentCommandScope(session:anchors:)`.

## Acceptance Criteria
