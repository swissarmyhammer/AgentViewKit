## What
Create `Sources/AgentViewKit/Thread/ItemViewOverrides.swift` and `Sources/AgentViewKit/Thread/Registries.swift`, per plan.md §3.6 and §7.

- `ItemViewOverrides`: one environment key per `ThreadItem` kind holding an optional `(Record) -> AnyView`. Typed modifiers `.systemPromptView`, `.userMessageView`, `.assistantMessageView`, `.reasoningView`, `.toolCallView`, `.structuredItemView`, `.compactionView`, `.errorView`, `.unknownItemView`.
- `StructuredItemRegistry`: `.structuredItem(_ schemaName: String) { … }` writes into an environment dictionary; last writer wins. `resolve(schemaName:)` returns the innermost registration or nil.
- `ContentBlockRegistry`: `.contentBlockView(for: ContentBlockKind) { … }`.
- `AttachmentRegistry`: `.attachmentView(for: UTType) { … }`. `resolve(type:)` walks `UTType.supertypes` by conformance to the nearest registration, then returns nil so the caller uses the generic chip.
- No views in this task. Only the environment plumbing and the resolution functions.
