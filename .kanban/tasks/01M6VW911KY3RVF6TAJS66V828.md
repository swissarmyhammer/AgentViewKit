## What
EditorKit makes the inspector look like a System Settings detail pane (EditorKit style.md, section "The inspector"):
- A field name is the placeholder of an empty value, and is always in the tooltip and the accessibility label.
- `.inspectorFieldLabels(.visible)` shows the names as Settings rows. In visible mode a read-only value uses the secondary text style.
- A Bool Field in an InspectorView draws as a switch at the trailing edge, with its name at the leading edge. No style is necessary.
- When a block shows only one group, EditorKit shows no section header for it (EK main 7919976b). Use `FieldGroup.header(.hidden)` only in a block with two or more groups.
- Menu ChoiceField and ToggleField do not change.
