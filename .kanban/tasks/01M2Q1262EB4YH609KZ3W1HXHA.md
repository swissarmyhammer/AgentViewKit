## What
The UI tests of the demo app (`Examples/AgentViewKitDemo/Tests/ACPTabEndToEndTests.swift`) use `XCUIApplication`. `Scripts/test-examples.sh` runs them with `xcodebuild test`. On this machine, the test runner does not start:

```
AgentViewKitDemoUITests-Runner encountered an error (The test runner failed to initialize for UI testing. (Underlying Error: Authentication canceled. System authentication is running.))
```

`automationmodetool` says:

```
Automation Mode is disabled.
This device requires user authentication to enable Automation Mode.
```

An agent cannot give the password. A person must do one of these steps:

- Run `sudo automationmodetool enable-automationmode-without-authentication` one time on the build machine, or
- Run `Scripts/test-examples.sh` one time in a logged-in session and approve the "Enable UI Automation" prompt.

## Acceptance Criteria
- [ ] `automationmodetool` does not say "requires user authentication", or the approval is given for the session that runs the tests.
- [ ] `Scripts/test-examples.sh` starts the UI test runner with no "failed to initialize for UI testing" error.
