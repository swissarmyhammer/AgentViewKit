## What
After the kit session model is gone, the kit copies of ACP value types have no use. The views use the ACP types directly. Source: update.md §4.5 (row 5).

- [ ] Delete from `Sources/AgentViewKit/Model/`: `ThreadState.swift`, `SlashCommand.swift`, `ConfigOption.swift`, `ContextUsage.swift`, `JSONValue.swift`, `PatchField.swift`, `WireValueEnum.swift`, and the kit `StopReason`, `ToolKind`, `ToolCallStatus`, `PlanEntry` and `AuthMethod` types. Delete `Sources/AgentViewKit/Sessions/SessionSummary.swift`.
- [ ] Keep a type only if a view needs a value that ACP does not define. Record each kept type and its reason in `Docs/decisions/acp-client-kit.md`.
- [ ] Change the remaining callers to the ACP types (`JSONValue`, `StopReason`, `ToolKind`, `ToolCallStatus`, `AvailableCommand`, `SessionConfigOption`, `AuthMethod`, `SessionInfo`).
- [ ] Delete the tests of the removed types. Add `PatchField` and `WireValueEnum` to `RemovedVocabularyTests`.

## Acceptance Criteria
- [ ] No source declares a type with the same name as an ACP type, except the kept types in the decision record.
- [ ] `swift test` and `Scripts/check-readme.sh` pass.
